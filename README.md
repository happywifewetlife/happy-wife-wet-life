# Happy Wife, Wet Life Website

This is a static website starter for Happy Wife, Wet Life.

## Files

- `index.html` - main website page
- `assets/css/styles.css` - design and layout
- `assets/js/main.js` - mobile menu and current year
- `assets/images/` - place your logo, decals, product mockups, and lifestyle photos here

## How to edit images

Replace placeholder sections in `index.html` with image tags, for example:

```html
<img src="assets/images/surfing-decal.png" alt="Happy Wife, Wet Life surfing decal">
```

## Free hosting option

Use GitHub Pages:

1. Create a GitHub account.
2. Create a new repository named `happy-wife-wet-life`.
3. Upload these files.
4. Go to Settings > Pages.
5. Under Branch, choose `main` and `/root`.
6. Save.
7. Add your custom domain in the Pages settings.
8. Update your domain DNS records to point to GitHub Pages.

## Domain DNS for GitHub Pages

Use these A records for the apex/root domain:

185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

For `www`, create a CNAME record pointing to:

YOUR-GITHUB-USERNAME.github.io

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.
